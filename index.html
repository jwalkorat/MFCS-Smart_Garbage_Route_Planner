RouteWise

Smart garbage collection route planning using Euler circuits and the Chinese Postman Problem.

Open Planner → See the maths

The problem

The problem

A garbage truck must pass through every street of a colony. Driving the same street twice wastes fuel, time and money.

Why it matters

Cities spend a large share of their waste budget on collection routes. Fewer repeated streets means lower cost and lower emissions.

Our approach

We model the colony as a graph and use discrete maths to find a route that repeats as few streets as possible.

How we model it

  • Junction = vertex ($v \in V$)
  • Street = edge ($e \in E$)
  • Length = weight ($w(e)$ in metres)
  • Number of streets at a junction = degree ($\deg(v)$)

The maths

Handshaking theorem

∑ deg(v) = 2 |E|

Every street is counted at both of its ends. So the number of odd junctions is always even.

Chinese Postman cost

Total = ∑ w(e) + min ∑ d(u,v)

M is a way of pairing up the odd junctions, and d(u,v) is the shortest distance between them.

Euler's theorem (for a connected graph)

Odd-degree junctions Result
0 odd Euler circuit exists — start and end at the same junction, covering every street exactly once.
2 odd Euler path exists — must start at one odd junction and finish at the other.
4 or more odd No route without repeating streets — solved using the Chinese Postman pairing.

Why: each time we pass through a junction we use one street to enter and one to leave, which uses 2 streets. So every junction we only pass through needs even degree. Only the start and end can be odd.

Did you know? A map can never have exactly one odd junction. The handshaking theorem forbids it.

Worked example

Map 1: 4-junction practice colony

Streets: AB = 2, AC = 3, AD = 4, BC = 6, BD = 5, CD = 1 (original length = 21).

All four junctions are odd. Pairings: AB + CD = 3, AC + BD = 8, AD + BC = 9. Cheapest = 3. Total = 21 + 3 = 24.

Real-world uses

Garbage trucks

Collecting household waste along every municipal street while minimizing fuel use.

Postal delivery

Planning mail carrier walks that service every block and return to the post office.

Snow ploughs

Clearing snow from every neighbourhood road after a storm with minimal deadheading.

Street sweeping

Scheduling mechanical sweepers to clean every curb across residential sectors.

Meter reading

Routing utility inspectors along every street segment to read water or gas meters.

Limits and assumptions

Lengths are straight-line distances measured on the map with the haversine formula, unless you type your own. Streets are two-way. The pairing step tries every pairing, so the planner supports up to 12 odd junctions.
